Current projects: Welcome to Snowcape

Over my life, I have found 2 main things that motivate me to work; money and passion. It turns out I'm pretty passionate about both the old internet and Animal Crossing. So a retro-style personal website about my favorite game is my favorite project to work on.

Welcome to Snowcape(formerly the Snowcape interactive map)

My big time passion project is a website centered around my island from Animal Crossing, hosted on https://snowcape.neocities.org/ and backed up in this repo. Neocities is a revival of the old Geocities, where people used to host personal websites back in the day. The site is all done in regular HTML/CSS/JavaScript, in order to match the retro vibe of Neocities. A personal website should reflect the person behind it, and my creative process is a bit messy and chaotic. Therefore, the aesthetics of the site, especially the index page, are intentionally maximalist.(or as some would say, a bit messy)
The site consists of several different sections;

The interactive map

Before my site was Welcome to Snowcape, it was the Snowcape interactive map. For the map itself, I tried placing a couple pins manually before deciding I needed to make a tool to place them. The mapping tool consists of a JavaScript frontend and a Python backend, communicating through websockets. The JS side lets the user cycle through a folder of images, assign coordinates to them, and send the id of the image alongside the coordinates to the python backend. The backend stores this info, and later uses it to generate the necessary HTML to place the pins and connect them to the relevant screenshot. It also copies every pinned screenshot into a seperate folder for use with the website to avoid storing unused images and wasting storage.

The fashion section

For the fashion section, I borrowed the idea of reusable components from modern frameworks, and wrote some Javascript to generate recurring HTML elements. The slideshows, slideshow controls, left/right placement of items and that little gradient on top of the text box were all generated for each showcase. The showcase containers themselves and textboxes were not generated, as the text content and coloring is distinct for each one. This was my first time coding reusable components, after all. I could probably automate it more if I rewrote it today.

The guestbook

A fun part of surfing the retro web is leaving little messages in people's guestbooks. There are several guestbook solutions available for free online, but none of them were customizable enough for me. So I made my own frontend. The actual recieving and storing of messages is done using HTML comment box, but my code hides most of the default comment section, and extracts the comments themselves in order to generate a new display. The input areas of the comment section are also moved and resized in order to fit on a letter, to complete the aesthetic.
The guestbook is probably my favorite bit of code I've done for the site, because the process of taking an existing bit of HTML that I cannot access or change, analyzing its components, and reshaping it as if it was modeling clay, was a really fun puzzle to figure out.

Meet the locals(or the timeline tearoom)

I do reuse the same profile box for every character, and play around with the .animate() function from JavaScript, so there is a bit of clever coding on this page. Most of it, however, is centered around writing rather than coding, so it's not the most interesting from a programming perspective.

Tourism(aka The W2SC Cyber-Brochure™)

The Cyber-Brochure™ is a collection of several neat little functions, like the before-and-after slider for the museum, a moveable ripoff of Clippy, an animation when warping to specific sections(with some random color variation) and some fun CSS tricks to recreate the visual of turning a page.
The layout is rather convoluted as well, and it is how I discovered the discrepancy between Windows and Linux font rendering. This led to me creating the font size changer widget, which is consistent across the entire site, and is also generated entirely by a script, meaning all I need to add to each page is a <script> tag for the whole thing to function.

Ai tech deck

A lot of employers these days put a lot of emphasis on using AI tools for coding. So I figured I needed at least a little experience with that stuff. So I put together a combination of a desktop pet and one of those finger skateboards, but with all the code being generated by ChatGPT.
Gotta be honest though, giving the AI full control of the code isn't fun. It may be efficient, but it's in no way creatively fulfilling. I got a solid idea of the key principles of AI-driven development, but for my unpaid hobby projects, I think I'll stick to writing the code myself and using AI as more of an oracle/advisor.
Anyway, complaints aside, the project can be found in this repo.
